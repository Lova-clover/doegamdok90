# Touchline Replay 90 멀티 경기 시뮬레이션 명세

최종 갱신: 2026-07-11  
상태: V6 구현 및 자동 검증 완료

## 1. 제품 약속

> 같은 실제 경기라도 포메이션, 위치, 교체, 전술 강도와 현장 지시가 다르면 공간, xG, 장면, 스코어가 달라진다.

정해진 애니메이션을 재생하는 전술판이 아니라 사용자의 입력으로 남은 경기를 다시 계산하는 결정론적 감독 시뮬레이터다.

## 2. 플레이 가능한 실제 경기

## 3. 입력과 출력

### 입력

- 포메이션: `4-2-3-1`, `4-3-3`, `3-4-3`, `5-4-1`
- 선수 위치: 11명의 직접 배치 좌표
- 선수 특성: 속도, 체력, 창의성, 결정력, 수비, 공중전
- 교체: 아웃·인 선수와 교체 시점
- 전술 강도: 전개 속도, 공격 폭, 압박 강도, 위험 감수
- 경기 맥락: 남은 시간, 스코어, 상대 공격·수비·전환·공중전·압박
- 현장 지시: 설계 유지, 공격 강화, 전환 안전 또는 박스 잠금

### 중간 지표

- 득점 위협
- 경기 통제
- 후방 안정
- 모멘텀
- 역습 위험
- 슈팅 품질
- 공중전 위협

### 출력

- 내 xG와 상대 xG
- 6개의 시간순 이벤트
- 각 이벤트의 재정렬·전진·압박 돌파·결정 4프레임
- 양 팀 22명 위치, 공 경로, 위험 구역
- 득점과 실점이 반영된 스코어
- 점유율, 슈팅, 유효 슈팅, 주요 경로
- 실제 경기 vs 내 선택 vs 코치 플랜 비교

## 4. 인과 설명 계약

편집 화면부터 시뮬레이션까지 다음 문장을 같은 순서로 유지한다.

1. **내가 바꾼 것**: 포메이션, 강도, 교체, 직접 이동, 현장 지시.
2. **생긴 공간**: 중앙 통로, 박스 도착 숫자, 공 뒤 간격, 압박 시작점.
3. **예상 변화**: 내 xG와 상대 xG의 기본 전술 대비 증감.
4. **보이는 장면**: 선수와 공이 네 프레임에 걸쳐 이동.
5. **결과**: 스코어와 미션 성공 여부.

각 이벤트의 `choiceEchoes`에는 해당 장면에 사용한 선택을 저장한다. 설명과 결과가 분리되지 않게 하는 핵심 계약이다.

## 5. 엔진 원칙

1. **결정론**: 같은 입력은 항상 같은 이벤트와 스코어를 만든다.
2. **트레이드오프**: 공격 폭과 위험을 높이면 득점 위협과 상대 역습 위험이 함께 오를 수 있다.
3. **미션별 가중치**: 추격은 득점·모멘텀, 수성은 통제·후방 안정의 비중이 높다.
4. **경기별 보정**: 상대 프로필, 남은 시간, 실제 위험 요인이 계수에 반영된다.
5. **과도한 공격 보정**: 일부 추격전에서 위험도가 지나치면 슈팅의 침착성과 전환 수비가 함께 낮아진다.
6. **목표별 판정**: 승리, 리드 유지, 패하지 않고 연장 진입을 분리한다.
7. **비예측 모델 고지**: 실제 승률·베팅 확률이 아닌 체험용 로컬 모델이다.

## 6. 기본 대응과 코치 플랜

| 경기 | 기본 대응 | 코치 플랜 | 핵심 변화 |
| --- | --- | --- | --- |
| 한국-가나 | 미션 실패 | 3:2 승리 | 위험 8을 4로 낮추고 백승호로 전환 통로 보호 |
| 한국-포르투갈 | 2:2 | 3:2 | 황희찬 투입과 측면 침투 강화 |
| 아르헨티나-프랑스 | 2:2 | 2:0 | 5-4-1과 리산드로로 박스 앞 두 줄 형성 |
| 벨기에-일본 | 3:4 | 3:2 | 펠라이니·샤들리로 높이와 전환 속도 확보 |
| 브라질-크로아티아 | 1:1 | 1:0 | 밀리탕 투입과 5-4-1로 중앙 역습 차단 |
| 일본-벨기에 | 2:3 | 2:2 | 마키노 투입, 후방 3명 유지로 연장 진입 |

자동 테스트는 모든 경기에서 기본 대응이 미션을 놓치고 코치 플랜이 목표를 달성하는지 검증한다.

## 7. 상태와 데이터 구조

- `scenarioCatalog`: 경기 메타데이터, 실제 사건, 출처, 로스터, 상대 프로필, 모델, 코치 플랜, 아카이브 정보
- `playerPortraits`: CC 라이선스 사진, 대체 텍스트, 저작자, 원본, 라이선스 URL
- `calculateTactic`: 입력을 중간 지표와 이유·경고 문장으로 변환
- `simulateMatch`: 지표를 xG, 이벤트, 4프레임 장면, 스코어, 통계로 변환
- `touchline-replay-90:sessions:v4`: 경기별 전술 상태 자동 저장
- 런타임 외부 API 없음: 키, 로그인, 결제 없이 전 기능 사용
