## 최종 판정

현재 13장은 시각적 완성도는 높지만 **그대로 제출하면 안 된다.**

필수 수정:

1. 모든 페이지 번호를 `/13`으로 통일한다.
2. 생성 UI를 실제 앱 화면 또는 `UX 시안` 표기가 있는 화면으로 교체한다.
3. 10장의 결과 수치를 실제 구현 결과와 일치시킨다.
4. 11장의 가상 경기 기록을 삭제한다.
5. 12장의 자체 평가 점수와 `심사기준 100%` 표현을 삭제한다.
6. 생성된 국기를 검증된 국기 에셋으로 교체한다.

## 9장 교정

삭제:

- `SHOT PATH`
- `SPEED 102.3 km/h`
- `DISTANCE 18.4 m`
- 실제 앱에 없는 선수 실사형 장면

교체 문구:

> 선수와 공이 연속 이동하고, 공이 골라인 구간에 도착한 뒤에만 GOAL이 표시됩니다.

하단 단계:

> 빌드업 → 패스 → 침투 → 슈팅 → 골라인 판정 → 결과 반영

## 10장 교정

실제 구현 증거 기준:

- 감독 점수: `92점`
- 포메이션: `4-2-3-1`
- 최종 스코어: `3:2`
- 매치 플랜: `3/3`
- 도전 코드 예시: `DG90-KRPT-65-92-3`

권장 제목:

> 실제 경기, 기준 전술, 내 선택, 코치 제안을 한 화면에서 비교합니다.

없는 수치인 `22회`, `0실점`, `3-4-2-1`, `3:0`은 삭제한다.

## 11장 교정

현재 프랑스-브라질 `1-2`, 득점 시각 `12·35·57·82`, KOR/BRA 선수 표시는 공식 사실처럼 보이는 가상 데이터이므로 삭제한다.

왼쪽 공식 사실 레이어:

> 대진 · 실제 스코어 · 득점 시각 · 주요 교체  
> 출처와 함께 저장하며 수치를 수정하지 않습니다.

오른쪽 자체 체험 모델 레이어:

> 능력치 · xG · 예상 스코어 · 이벤트 · 감독 점수  
> 공식 예측이 아닌 로컬 결정론적 체험 모델입니다.

하단 고지:

> 비공식 팬 시뮬레이션 · FIFA, 대표팀, 선수와 제휴 관계 없음 · 자체 모델 수치는 공식 예측이 아님

## 12장 교정

자체 평가 점수와 평균을 모두 삭제한다. 심사위원에게 점수를 미리 부여하는 인상을 피한다.

권장 제목:

> 대회의 네 가지 평가 기준을 실제 동작으로 증명합니다.

권장 내용:

- 참신성: 결정적 순간 아카이브와 운명 분기
- 감독 경험: 배치·교체·전술·현장 지시가 장면과 결과에 반영
- 완성도: 브라우저 즉시 실행·모바일 대응·자동 저장·테스트
- 기획/구현: 내 판단에서 리포트까지 하나의 인과 구조

하단 결론:

> 아이디어가 아니라, 직접 조작되고 비교되고 설명되는 제품입니다.
