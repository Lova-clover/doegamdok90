## 1. 결론

Touchline Replay 90은 이제 단순 포메이션 편집기가 아니라 **실제 월드컵의 아쉬운 순간을 다시 지휘하고, 내 선택이 공간·xG·장면·결과를 어떻게 바꿨는지 증명한 뒤 같은 조건으로 친구와 겨루는 반사실 감독 리플레이**다.

현재 구현은 최종 10팀 진입 가능성이 높은 편이며, 내부 심사 기준에 자체 대입하면 **95/100 목표 수준**이다. 수상을 보장할 수는 없지만, 평가표와 실제 구현의 일치도는 강하다. 남은 가장 큰 위험은 제품이 아니라 제출 운영이다. 현재 저장소에는 아직 첫 커밋, GitHub 공개 URL, 배포 URL, 유튜브 시연 영상이 없다.

## 3. 독보적인 사용 이유

일반 전술판은 사용자가 선수를 놓고 끝난다. Touchline Replay 90은 다음 네 단계가 모두 작동한다.

1. **후회가 있는 실제 경기**를 고른다.
2. 감독처럼 직접 전술과 선수를 바꾼다.
3. 초기 전술과 내 선택의 결과를 같은 65분 조건에서 비교한다.
4. 받은 목표 점수를 넘겼는지 판정하고 다음 사용자에게 도전장을 보낸다.

핵심 한 줄은 그대로 유지한다.

> 내가 감독이었다면, 그 경기의 운명은 달라졌을까?

### 4.2 발견하고 고친 문제

1. **첫 방문이 자동 저장만으로 ‘저장한 전술 이어가기’로 바뀌는 문제**  
   실제로 경기 안에 들어간 시나리오만 `enteredScenarioIds`로 별도 기록하도록 수정했다. 새로고침해도 첫 60초 추천 CTA가 유지된다.

2. **작은 전술 수정이 스코어를 바꾸지 않으면 효과가 없어 보이는 문제**  
   스코어 전에도 xG 변화가 먼저 보이도록 인과 문구와 운명 분기 강조 상태를 추가했다.

3. **720px 높이 데스크톱에서 상단과 하단 인과 스트립이 잘리는 문제**  
   콤팩트 높이 레이아웃을 추가하고, 중복 정보인 경기 타임라인은 이 높이에서 숨겼다.

4. **현장 지시 클릭 후 준비 화면이 위로 밀리는 문제**  
   시뮬레이션 셸과 내부 높이를 조정해 클릭 전후 `scrollTop=0`을 유지했다.

5. **리플레이 문장 조사 오류와 경로 점이 공처럼 보이는 문제**  
   `박스 과부하: 경기의 다음 경로가 바뀝니다`로 문장을 수정하고, 경로 웨이포인트를 속이 빈 반투명 링으로 바꿨다.

6. **모바일 리포트에서 세 번째 매치 플랜 카드가 잘리는 문제**  
   560px 이하에서 카드를 세로 스택으로 전환했다.

7. **공유 도전 링크의 목표가 사라지고 성공 여부가 판정되지 않는 문제**  
   매치데이 스트립에 목표 점수를 유지하고, 리포트에서 받은 코드·목표·내 점수·성공/동점/차이를 판정하도록 확장했다.
