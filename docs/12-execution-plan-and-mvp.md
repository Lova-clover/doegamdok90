# Touchline Replay 90 - 2026 실행계획 및 MVP 현황

> 이 문서는 초기 V3 실행 기록이다. 현행 V6의 실제 경기 6개와 최종 구조는 `docs/13-multi-match-simulation-spec.md` 및 `docs/15-heartbreak-archive-v6.md`를 기준으로 한다.

작성 기준일: 2026-07-10

## 1. 최종 아이디어 재정립

### 제품 정의

Touchline Replay 90은 전술판이 아니다. 실제 월드컵 경기의 결정적 순간에 사용자를 감독으로 투입하고, 짧은 시간 안에 내린 선택이 어떤 대체 경기 서사를 만드는지 보여주는 **설명 가능한 감독 의사결정 리플레이**다.

### 한 줄 제안

> 실제 월드컵의 운명이 갈린 22분. 이번에는 당신이 감독입니다.

### 첫 번째 대표 시나리오

- 경기: 2026 월드컵 대한민국 2:1 체코
- 진입 시점: 60분, 대한민국 0:1 체코
- 실제 기준선: 59분 실점, 62분 황희찬 투입, 67분 황인범 동점골, 69분 엄지성·오현규 투입, 80분 오현규 역전골
- 사용자 미션: 22분 안에 경기를 뒤집되 중앙 역습과 세트피스 위험을 통제한다.

## 2. 대회가 실제로 원하는 것

[공식 대회 안내](https://daker.ai/public/hackathons/world-cup-manager-tactics-web-challenge)를 제품 요구사항으로 번역하면 다음과 같다.

1. 사용자가 직접 드래그, 클릭, 배치, 조작해야 한다.
2. 월드컵 데이터가 장식이 아니라 의사결정 맥락과 결과에 연결돼야 한다.
3. 첫 화면에서 "내가 감독이다"라는 감정이 생겨야 한다.
4. 동적 기능이 실제로 작동하고, 로그인이나 별도 API 키 없이 완주돼야 한다.
5. 기획서의 핵심 약속과 배포 서비스의 핵심 기능이 동일해야 한다.

따라서 우승 전략은 기능 수를 늘리는 것이 아니라, **한 번의 감독 선택이 브리핑 → 조작 → 코치 반응 → 시뮬레이션 → 비교 리포트까지 끊김 없이 이어지는 것**이다.

## 3. 해결할 사용자 문제

### 문제 A - 축구를 잘 모르면 전술판이 어렵다

기존 전술 도구는 빈 경기장과 많은 옵션을 제공한다. 전문가에게는 자유지만 일반 팬에게는 시작 지점을 알 수 없는 부담이다.

해결:

- 안정, 균형, 승부의 세 가지 시작안을 제공한다.
- 각 안은 포메이션과 전술 수치를 함께 설정한다.
- 사용자는 선수 한 명과 전술 두 개만 바꿔도 완주할 수 있다.

### 문제 B - 결과가 임의로 느껴질 수 있다

완전한 축구 예측은 해커톤 범위를 벗어나며, 근거 없는 AI 문장은 신뢰를 잃기 쉽다.

해결:

- 동일한 입력은 동일한 결과를 내는 로컬 규칙 엔진을 사용한다.
- 모든 점수는 폭, 템포, 교체, 중앙 안전핀, 역습 위험 신호로 계산한다.
- 결과마다 긍정 이유 3개와 트레이드오프 1개 이상을 보여준다.
- "미래 예측"이 아니라 "선택에 따른 대체 경기 서사"임을 분명히 한다.

### 문제 C - 일반 투표자는 전술 점수에 관심이 적다

해결:

- 공격 72 같은 원시 수치보다 `운명 변화 +21`을 전면에 둔다.
- 최종 결과를 감독 유형으로 요약한다.
- 실제 경기, 내 선택, 코치 제안을 한 화면에서 비교한다.

## 4. 차별화 구조

### Decision Moment

분, 점수, 남은 시간, 미션, 제약을 한 번에 제시한다. 사용자는 설명을 읽는 대신 위기 상황에 들어간다.

### Coach Room Trio

- 수석코치: 공격 구조와 즉시 실행할 행동
- 분석관: 상대 약점과 전환 위험
- 피지컬코치: 체력과 교체 타이밍

외부 AI API 없이 규칙 기반으로 반응하므로 심사 환경에서도 안정적이다.

### Fate Meter

실제 60분 기준선과 비교해 사용자의 선택이 경기 경로를 얼마나 바꾸는지 -30에서 +30으로 표시한다.

### Real vs Me vs Coach

실제 결과, 사용자 결과, 코치 권장안을 같은 기준으로 비교한다. 데이터, 인터랙션, 결과 엔진이 연결됐다는 가장 강한 증거다.

## 5. 평가항목별 우승 설계

| 평가항목 | 목표 | 제품에서 증명할 장면 |
|---|---:|---|
| 참신성 | 27~30/30 | 실제 경기의 특정 분으로 진입, 운명 변화, 3자 비교 |
| 감독 경험 | 22~25/25 | 시간 압박, 직접 배치, 교체, 코치진의 즉시 반응 |
| 완성도 | 22~25/25 | 로그인·API 키 없이 전체 흐름 작동, 모바일 지원 |
| 기획/구현 | 18~20/20 | PRD, 데이터, UI, 시연 영상이 동일한 핵심 루프 사용 |

## 6. 현재 MVP 구현 범위

구현 완료:

- 2026 한국-체코 Decision Moment 시작 화면
- 4개 포메이션 프리셋
- 11명 선수 드래그와 선택 후 필드 클릭 이동
- 키보드 방향키 이동 대안
- 벤치 선수 교체와 최대 3회 교체 상태
- 템포, 폭, 압박, 위험 감수 컨트롤
- Coach Room Trio 실시간 조언
- Goal Threat, Control, Rest Defense, Momentum 계산
- 운명 변화 -30~+30 계산
- 4개 이벤트로 구성된 60'~82' 시뮬레이션
- 감독 점수, 페르소나, 이유, 경고 리포트
- Real Match vs My Call vs Coach Pick 비교
- 모바일 보드/브리핑/코치진/전술 탭
- 공유 API 또는 클립보드 폴백

의도적으로 제외:

- 회원가입과 서버 데이터베이스
- 유료 또는 키가 필요한 AI API
- 실시간 경기 API
- 공식 로고, 선수 사진, 방송 영상
- 완전한 물리 기반 축구 시뮬레이션

## 7. 데이터와 저작권

- 경기 사실, 선수 명단, 교체와 득점 시점은 [FIFA 공식 경기 리포트](https://fdp.fifa.org/assetspublic/ce281/r12450/pdf/FullTimeMatchReport-English.pdf)를 기준으로 했다.
- 확장 경기 목록은 [OpenFootball World Cup 데이터](https://github.com/openfootball/worldcup)의 CC0 데이터 사용을 우선한다.
- 선수 능력치와 전술 가중치는 서비스 목적에 맞게 직접 작성한 시뮬레이션 값이다.
- 경기장 이미지는 프로젝트를 위해 생성한 독립 자산이다.
- 공식 엠블럼, 선수 얼굴, 유니폼 디자인, 방송 캡처는 사용하지 않는다.

## 8. 경쟁 서비스에서 배운 것

[TacticsBoard](https://tacticsboard.app/)와 [Tactic Board](https://tacticboard.app/) 같은 서비스는 드래그, 포메이션 분석, 애니메이션을 제공한다. 따라서 단순히 선수를 움직이는 기능만으로는 차별화되지 않는다.

Touchline Replay 90의 차이는 다음에 있다.

- 빈 보드가 아니라 실제 경기의 특정 순간에서 시작한다.
- 전술을 저장하는 데서 끝나지 않고 선택의 결과를 재생한다.
- 결과를 실제 경기와 비교한다.
- 비전문가도 세 가지 시작안으로 즉시 참여한다.

## 10. 90초 시연 영상 구조

1. 0~8초: "60분, 한국 0:1 체코. 22분 안에 뒤집어라."
2. 8~18초: 비전문가용 균형안 선택
3. 18~35초: 황희찬 교체와 선수 직접 드래그
4. 35~48초: 운명 변화 +8에서 +21, 분석관의 중앙 안전핀 설명
5. 48~64초: 시뮬레이션의 동점·역전 이벤트
6. 64~80초: 실제 경기 vs 내 선택 vs 코치 제안
7. 80~90초: 감독 유형 카드와 "이번엔 당신이 감독입니다"

## 12. 성공 판단 기준

MVP가 다음 조건을 만족하면 기획 단계가 아니라 수상 후보 수준의 제품으로 본다.

- 첫 방문자가 10초 안에 무엇을 하는 서비스인지 설명할 수 있다.
- 축구 비전문가가 별도 도움 없이 3분 안에 리포트를 본다.
- 모든 결과 문장이 사용자가 실제로 한 선택과 연결된다.
- 시연 영상에서 운명 변화가 눈에 띄게 움직인다.
- 배포 URL에서 로그인, API 키, 설치 없이 완주된다.
