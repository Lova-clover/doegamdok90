# Touchline Replay 90 V8 최종 명세

> 이 문서는 V8 설계 기록이다. 현재 제출 기준은 `docs/18-player-identity-rights-gate-v9.md`이며, V9에서 실존 선수명과 매칭되지 않는 합성 얼굴을 제거했다.

작성일: 2026-07-11  
버전: Continuous Replay & Rights-safe Faces V8

## 1. 이번 개선이 해결한 문제

1. 4개 장면 사이에 멈춤이 생겨 선수와 공이 뚝뚝 끊겨 보였다.
2. 득점도 일반 장면과 같은 속도로 넘어가 골을 넣었다는 감정적 보상이 약했다.
3. 기존 일러스트 얼굴은 전술판의 현실감을 떨어뜨렸다.
4. 실제 선수 사진은 사진 저작권과 선수의 초상·퍼블리시티 권리를 동시에 검토해야 했다.

V8은 실제 얼굴을 무단 사용하지 않고도 현실감을 높이며, 득점까지 하나의 연속 플레이로 느끼게 만드는 데 집중한다.

## 2. 연속 리플레이 엔진

- 엔진의 `재정렬 → 전진 → 압박 돌파 → 결정` 4개 체크포인트는 유지한다.
- 화면은 체크포인트 좌표를 그대로 점프하지 않고 `requestAnimationFrame`으로 매 순간 보간한다.
- 선수 22명, 공, 패스 경로, 위험 구역이 같은 진행률을 사용한다.
- 이동 구간은 기본 980ms, 일반 장면 정지는 620ms, 득점 장면 정지는 1,380ms다.
- 2배속은 같은 경로를 절반 시간에 재생하며 현재 위치에서 이어진다.
- 이벤트 사이 전환은 짧은 방송형 페이드로 구분해 시간 점프는 알리되 장면 내부 움직임은 끊지 않는다.
- 모션 감소 설정에서는 각 구간을 80ms로 축약한다.

## 3. 골 순간 연출

득점 체크포인트에 도달하면 다음 반응을 한 번만 실행한다.

1. 공이 확대·회전하며 슈팅의 마지막 가속을 표현한다.
2. 피치 카메라가 짧게 확대되고 밝기가 올라간다.
3. 스코어보드가 펄스하며 새 스코어를 강조한다.
4. 득점 팀·득점 주체·스코어가 포함된 `GOAL!` 오버레이가 나타난다.
5. 경기장 사운드를 켠 경우 관중음이 1.7초 동안 증폭된다.
6. 지원 기기에서는 짧은 진동 패턴을 실행한다.
7. 득점 설명 패널도 같은 순간에 강조된다.

실점도 동일한 구조를 사용하되 상대 팀 색과 경고 톤으로 구분한다.

## 4. 실사형 합성 선수 이미지

- 프로젝트 전용으로 생성한 32명의 가상 축구 선수 헤드샷을 사용한다.
- 실존 인물, 선수, 유명인을 참조하거나 닮게 만들지 않았다.
- 얼굴은 선수 이름의 고정 해시로 선택해 같은 이름이 다른 경기에서도 같은 모습으로 나온다.
- 상대 팀 익명 선수는 경기·포지션 기반 고정 시드로 선택한다.
- 2개의 800×800 JPEG 아틀라스로 제공해 전체 용량을 약 244KB로 제한한다.
- 전술판, 선택 선수, 벤치, 리플레이가 동일한 얼굴 자산을 공유한다.

## 5. 실제 선수 얼굴 권리 판단

실제 얼굴은 “무료 사진을 찾으면 문제없다”로 판단할 수 없다.

- [DAKER 대회 규정](https://daker.ai/public/hackathons/world-cup-manager-tactics-web-challenge)은 제출 이미지의 권리 준수를 요구한다.
- [Wikimedia Commons](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia/en)는 자유 라이선스와 별개로 personality rights가 남을 수 있다고 명시한다.
- [국가법령정보센터](https://law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1020635549)는 경제적 가치가 있는 성명·초상 등 식별표지를 무단으로 자신의 영업에 사용하는 행위를 규율한다.
- [지식재산처](https://kipo.go.kr/ko/kpoBultnDetail.do?aprchId=BUT0000029&menuCd=SCD0200618&ntatcSeq=19495&sysCd=SCD02)는 손흥민 등 유명 스포츠인의 얼굴과 이름이 보호 대상임을 설명한다.

따라서 선수 또는 권리관리 주체의 명시적 허락과 사진 라이선스를 모두 확보하기 전에는 실제 얼굴을 제품에 넣지 않는다. 이는 법률 자문이 아니라 대회 제출 리스크를 낮추기 위한 보수적 제품 결정이다.

## 6. 검증 상태

- 16개 Node 테스트 통과.
- 프레임 중간 좌표·공 경로 보간 테스트 추가.
- 다음 체크포인트의 포커스 강조 시점 테스트 추가.
- Vite 프로덕션 빌드 통과.
- JavaScript 번들 467KB, gzip 145KB로 DiceBear 제거 전보다 감소.
- `npm audit` 취약점 0건.

## 7. 시연 영상에서 보여줄 장면

1. 선수 얼굴을 선택하고 위치를 바꾼다.
2. 같은 얼굴이 리플레이에서 부드럽게 전진하는 모습을 보여준다.
3. 공이 마지막 패스를 따라 이동하는 동안 `내가 바꾼 것`을 함께 보여준다.
4. 슈팅과 동시에 GOAL 오버레이·스코어 변화·관중음 증폭을 보여준다.
5. 실제 결과와 내 결과를 비교해 조작과 보상의 연결을 마무리한다.
