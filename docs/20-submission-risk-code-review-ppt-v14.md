> 이 문서는 실무 제출 리스크를 줄이기 위한 점검 자료이며 법률 자문은 아니다. 운영 규정의 해석이 필요한 항목은 반드시 대회 공식 게시판 답변을 보관한다.

## 1. 결론

Touchline Replay 90의 독보적 가치는 단순한 포메이션 편집이 아니라, 실제 월드컵의 아쉬운 결정 순간에 들어가 **내 선택 → 생긴 공간 → 장면 변화 → 결과 비교**를 한 번에 체험하는 감독 의사결정 리플레이라는 점이다.

현재 앱은 6개 경기, 선수 배치·교체·전술 조정, 설명 가능한 변화 지표, 연속 장면 시뮬레이션, 골라인 판정, 감독 리포트까지 실제로 작동한다. 선수 사진·합성 닮은꼴·공식 로고·중계 화면을 사용하지 않고, 경기 사실과 자체 모델 값을 분리 고지하여 초상권·저작권·오인 가능성도 낮췄다.

다만 **현재 상태 그대로는 제출 불가**다. 로컬 저장소에 최초 커밋이 없고, 외부 배포 URL·GitHub URL·YouTube 시연영상이 없다. 세 항목을 제출 전에 확보하지 못하면 작품 완성도와 관계없이 결격 가능성이 매우 높다.

## 2. 최종 발견사항

### P0 · 제출 자격 차단

1. `git status` 기준 저장소에 아직 최초 커밋이 없다. 제출 가능한 GitHub URL과 검증 가능한 이력이 없다.
2. 현재 확인 가능한 주소는 로컬 개발 서버뿐이다. 심사 기간 동안 외부에서 로그인·API 키 없이 접속 가능한 배포 URL이 필요하다.
3. 전체 흐름을 보여주는 YouTube 시연영상 링크가 없다.
4. 2026년 8월 3일 10:00 이후 GitHub 커밋이 확인되면 실격 처리될 수 있으므로, 최종 태그·릴리스·커밋 해시를 마감 전에 동결해야 한다.

### P1 · 공식 확인이 필요한 규정 모호성

대회 페이지 상단에는 “2026 FIFA 월드컵 데이터를 활용”이라고 적혀 있으나, 상세 데이터 설명에는 특정 연도·대회·선수 구성에 제한이 없다고 안내되어 있다. 현재 앱은 2018·2022 월드컵 경기 사례를 사용한다. 운영진의 공식 게시판 답변을 받아 스크린샷과 URL을 보관해야 한다.

공식 문의 문안:

> 대회 페이지 상단에는 2026 FIFA 월드컵 데이터 활용으로 표기되어 있으나 데이터 설명에는 특정 연도·대회 제한이 없다고 안내됩니다. 2018·2022 실제 월드컵 경기 기록을 활용한 비공식 전술 시뮬레이션도 심사 대상에 문제가 없는지 확인 부탁드립니다.

추가 문의 문안:

> FIFA 공식 경기 기사에서 날짜·스코어·득점·교체와 같은 소량의 사실 정보만 직접 큐레이션하고 원문 출처 링크를 제공하며, 로고·사진·영상·중계 그래픽은 사용하지 않는 방식이 대회 데이터 활용 요건에 부합하는지 확인 부탁드립니다.

## 3. 코드리뷰 결과

### 수정 완료

1. 브라우저 저장소가 차단되거나 용량을 초과해도 앱이 중단되지 않도록 `localStorage.setItem`을 예외 처리했다.
2. 외부 출처 링크에 `rel="noopener noreferrer"`를 적용했다.
3. 경기 보관함에 비공식 팬 시뮬레이션·비제휴·자체 모델 고지를 상시 노출했다.

5. 공개 대회명에서 불필요한 FIFA 표기를 제거해 공식 제휴 오인을 줄였다.
6. 고정된 “22분” 메타 설명을 다양한 개입 시점을 포괄하는 문구로 수정했다.
7. `NOTICE.md`에 비제휴, 데이터, 초상, 생성 자산, 오픈소스, 권리 요청 절차를 정리했다.
8. 테스트에 FIFA 출처 도메인과 공개 라벨의 FIFA 표기 금지 규칙을 추가했다.

### 남은 기술 리스크

1. 실제 외부 호스팅 환경의 새로고침·라우팅·모바일 네트워크·Safari 검증은 배포 URL이 생긴 뒤 다시 해야 한다.
2. 브라우저 저장 데이터는 기기별 로컬 상태이므로 심사자에게는 초기화된 데모 경로가 기본으로 보여야 한다.
3. 소리 자동재생은 브라우저 정책상 사용자 입력 이후에만 활성화될 수 있으므로, 시연영상에서는 사운드 버튼을 직접 켜는 장면을 넣는다.
4. 현재 결정론적 엔진은 설명 가능성과 재현성을 우선한다. 실제 경기 예측 AI로 홍보하지 말고 “체험용 전술 결과 모델”로 일관되게 설명한다.
