# Touchline Replay 90 V7 최종 명세

작성일: 2026-07-11  
버전: Flag Matchup & Player Face UX V7

> 이 문서는 V7 설계 기록이다. 현재 제출 기준은 `docs/18-player-identity-rights-gate-v9.md`이며, V9에서 합성 얼굴을 제거하고 유니폼·등번호 선수 식별과 초상 권리 게이트로 교체되었다.

## 1. 최종 제품 정의

> 실제 월드컵의 아쉬운 순간을 국기 대진으로 고르고, 얼굴이 보이는 선수들을 직접 움직여, 내 결정이 공간과 경기 결과를 어떻게 바꿨는지 연속 장면으로 확인하는 감독 리플레이.

서비스가 해결하는 핵심 문제는 “전술을 바꿨는데 왜 결과가 달라졌는지 모르겠다”이다. V7은 경기 식별, 선수 식별, 조작, 원인 설명을 하나의 시각 언어로 연결한다.

## 2. V7에서 바뀐 것

| 기존 불편 | V7 해결 |
| --- | --- |
| 경기 카드가 선수 사진 중심이라 국가 대항전 느낌이 약함 | 모든 경기 카드를 실제 국기 `VS` 국기 구조로 통일 |
| 실제 사진은 선수마다 확보하기 어렵고 권리 고지가 복잡함 | 실제 사진을 완전히 제거하고 MIT 비실사 아바타 사용 |
| 경기장 숫자 토큰만으로 선수가 잘 구분되지 않음 | 선수 ID마다 고정되는 얼굴과 작은 등번호 배지 조합 |
| 선수를 선택한 뒤 다음 행동이 모호함 | 경기장 위에 현재 선택 선수와 “필드 클릭” 다음 행동 표시 |
| 편집 화면과 시뮬레이션에서 선수가 다르게 느껴짐 | 같은 아바타를 전술판, 벤치, 리플레이에 계속 사용 |

## 3. 핵심 화면

### 3.1 아쉬운 경기 보관함

- 6개 실제 월드컵 분기점을 국기 대 국기 카드로 표시한다.
- 카드에는 대진, 개입 분, 현재 스코어, 라운드, 감정 태그를 표시한다.
- 선택한 경기의 큰 패널에서도 두 국기, 국가명, 개입 시점 스코어를 먼저 보여준다.
- 실제 결과, 팬의 한마디, 내 미션, 추천 전술은 그 아래에서 의사결정을 돕는다.

### 3.2 전술 보드

- 선수 얼굴, 등번호, 이름을 하나의 토큰으로 묶는다.
- 선수 선택 시 민트색 링으로 즉시 강조한다.
- 현재 선택 선수, 포지션, 등번호와 다음 행동을 경기장 바로 위에 유지한다.
- 드래그, 선수 선택 후 필드 클릭, 키보드 방향키를 모두 지원한다.

### 3.3 벤치와 교체

- 벤치 카드도 동일한 얼굴 아바타를 사용해 교체 대상을 빠르게 찾는다.
- 현재 선택한 필드 선수와 교체 가능한 선수만 활성화한다.
- 골키퍼 교차 교체, 교체 한도, 미선택 상태를 사전에 차단한다.

### 3.4 연속 시뮬레이션

- 홈과 상대 팀 22명을 얼굴 토큰으로 표시한다.
- 상대 선수는 경기 ID 기반 익명 얼굴을 사용해 팀만 구분하고 실제 인물을 가장하지 않는다.
- 재정렬, 전진, 압박 돌파, 결정의 4프레임에서 같은 선수 얼굴이 이동한다.
- 선택한 전술, 생긴 공간, xG 변화, 장면, 결과가 같은 용어로 반복된다.

## 4. 최종 유저 플로우

1. 국기 대진 카드에서 아쉬운 경기를 선택한다.
2. 실제 결과와 개입 시점, 미션을 확인한다.
3. 추천 프리셋 또는 저장한 전술로 입장한다.
4. 얼굴 토큰을 선택하고 드래그하거나 필드를 클릭해 이동한다.
5. 벤치 얼굴을 눌러 교체하고 포메이션·강도를 조정한다.
6. 인과 스트립에서 바꾼 것, 생긴 공간, xG 변화를 확인한다.
7. 현장 지시를 확정하고 연속 장면을 재생한다.
8. 실제 경기, 내 선택, 코치 플랜을 비교한다.
9. 반대편 벤치 또는 다른 국기 대진으로 재도전한다.

## 5. 우승 가능성을 높이는 차별점

| 평가 항목 | 심사 화면에서 보이는 증거 |
| --- | --- |
| 참신성 30 | 팬의 아쉬움으로 고르는 경기, 한 경기 두 감독, 국기 기반 월드컵 아카이브 |
| 감독 경험 25 | 얼굴 선수 직접 조작, 선택 상태, 교체, 현장 지시, 같은 얼굴의 연속 리플레이 |
| 완성도 25 | 외부 키 없음, 자동 저장, 결정론 엔진, 14개 테스트, 보안 취약점 0건 |
| 기획·구현 20 | `선택 → 공간 → 확률 → 장면 → 결과` 구조가 모든 화면에 일치 |

첫 10초에는 국기 대진과 실제 경기성이, 다음 20초에는 얼굴 선수를 직접 조작하는 감독 경험이 보여야 한다. 시연의 절정은 숫자 결과가 아니라 같은 얼굴들이 달라진 위치로 움직여 실점 통로를 닫는 장면이다.

## 6. 데이터와 권리

- 경기 사실은 시나리오별 FIFA 공식 경기 리포트를 연결한다.
- 국기는 MIT 라이선스 `country-flag-icons`를 사용한다.
- 얼굴은 MIT 라이선스 DiceBear의 `notionists-neutral` 스타일을 로컬에서 생성한다.
- 아바타는 실존 선수의 초상이나 닮은꼴이 아니다.
- 실제 선수 사진, FIFA 로고, 국가대표 엠블럼, 방송 캡처를 사용하지 않는다.
- xG와 전술 결과는 실제 공식 예측치가 아닌 체험용 결정론 모델이다.

## 7. 구현·검증 상태

- React 19, Vite 6.4.3, dnd-kit 기반.
- 6개 경기, 각 16명 로스터, 경기별 독립 자동 저장.
- 14개 Node 테스트 통과.
- 프로덕션 빌드 통과.
- `npm audit` 개발·런타임 의존성 0건.
- 주요 조작은 마우스, 터치, 키보드로 수행 가능.

## 8. 90초 시연 영상 V7

1. 0-10초: 국기 대 국기 아쉬운 경기 보관함을 빠르게 훑는다.
2. 10-18초: 브라질 대 크로아티아, 114분 1:0을 선택한다.
3. 18-32초: 프레드 얼굴을 선택하고 밀리탕 얼굴을 눌러 교체한다.
4. 32-45초: 5-4-1, 위험 2로 바꾸고 중앙 통로·상대 xG 변화를 보여준다.
5. 45-66초: 같은 얼굴들이 재정렬하고 역습 통로를 닫는 연속 장면을 재생한다.
6. 66-78초: 실제 1:1과 내 리드 수성 결과를 비교한다.
7. 78-90초: 벨기에 대 일본을 양쪽 벤치에서 플레이할 수 있음을 보여준다.

## 9. 최종 제출 체크

- [ ] 첫 화면의 모든 경기 카드에 두 국기가 정확히 표시된다.
- [ ] 전술판, 벤치, 리플레이에서 같은 선수 얼굴이 유지된다.
- [ ] 모바일에서 얼굴, 이름, 등번호, 클릭 영역이 겹치지 않는다.
- [ ] 모든 경기가 추천 플랜으로 목표를 달성하고 기본 플랜과 다른 결과를 낸다.
- [ ] 배포 URL, GitHub, PDF, 발표자료, 시연 영상의 V7 설명이 일치한다.
