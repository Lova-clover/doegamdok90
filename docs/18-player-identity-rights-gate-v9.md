# Touchline Replay 90 V9 최종 명세

작성일: 2026-07-11  
버전: Verified Player Identity V9

## 1. 해결한 문제

실존 선수 이름 옆에 닮지 않은 합성 얼굴을 붙이면 이미지 품질과 무관하게 사용자는 즉시 불일치를 느낀다. 작은 경기장 토큰에서는 얼굴 자체도 식별 정보로 기능하지 못한다. V9은 부정확한 얼굴을 없애고 감독이 실제로 사용하는 정보인 국가 색상, 등번호, 선수명, 포지션과 위치를 전면에 둔다.

## 2. 최종 선수 표현

- 경기 선택은 국기 대 국기 구성을 유지한다.
- 전술판 선수는 국가 유니폼 색상의 `TShirt` 마커와 실제 등번호로 표시한다.
- 선수명은 마커 아래에 유지해 번호를 모르는 사용자도 바로 식별한다.
- 선택 안내, 벤치 카드와 리플레이도 같은 유니폼·번호 규칙을 공유한다.
- 상대 선수는 상대 국가 색상과 번호로 구분하며 존재하지 않는 얼굴을 가장하지 않는다.
- 밝은 유니폼은 어두운 번호, 어두운 유니폼은 흰 번호를 자동 선택한다.

## 3. 실제 얼굴을 위한 권리 게이트

선수 데이터의 `portrait`는 아래 네 항목이 모두 있을 때만 렌더링된다.

1. `rightsStatus: "cleared"`
2. 사진 파일 또는 URL인 `src`
3. 저작권 라이선스인 `license`와 표시 문구인 `attribution`
4. 선수 또는 권리관리 주체의 허가 증빙인 `permissionReference`

하나라도 빠지면 자동으로 유니폼 마커를 사용한다. 현재 제출 데이터에는 승인 초상이 없으므로 실제 얼굴이나 닮은꼴을 표시하지 않는다.

## 4. 제품 판단

이 방식은 얼굴을 숨기기 위한 임시 대안이 아니라 전술 조작에 더 적합한 정보 설계다. 얼굴보다 번호와 이름이 작은 화면에서 선명하고, 드래그 중에도 선수를 놓치지 않으며, 전술판과 시뮬레이션의 시각 언어가 일치한다. 권리가 확보된 정확한 초상이 생기면 컴포넌트 교체 없이 해당 선수만 단계적으로 활성화할 수 있다.

## 5. 검증

- 6개 경기의 모든 선수는 번호·이름·포지션을 유지한다.
- 18개 Node 테스트가 통과한다.
- 권리 증빙이 불완전한 초상은 차단된다.
- 밝고 어두운 유니폼의 번호 대비가 테스트된다.
- Vite 프로덕션 빌드와 `npm audit`가 통과한다.
