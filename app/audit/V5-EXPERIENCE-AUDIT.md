# Touchline Replay 90 V5 감독 경험 개선 감사

감사일: 2026-07-10  
검증 환경: Codex 인앱 브라우저, 데스크톱 1440 x 900, 모바일 390 x 844

## 해결한 핵심 문제

| 기존 문제 | 사용자 영향 | V5 해결 |
| --- | --- | --- |
| 내부 화면이 검고 패널 비중이 높음 | 경기장이 아니라 분석 대시보드처럼 느껴짐 | 밝은 터치라인 작업공간, 큰 탑다운 피치, 흰색 전술 패널로 전환 |
| 전술을 바꿔도 결과와 연결되지 않음 | 조작이 숫자 장난처럼 보임 | 포메이션·강도·교체·직접 이동 좌표를 전술 지문과 장면 엔진에 전달 |
| 시뮬레이션이 점 3개와 텍스트 목록 중심 | 공감과 경기 몰입이 약함 | 양 팀 22명, 공, 패스 경로, 압박·전환 구역을 장면별로 시각화 |
| 공격 지시의 대가가 불분명함 | 어떤 선택이 좋은지 학습하기 어려움 | 박스 과부하는 내 xG와 상대 xG를 함께 상승시키고 실점 장면으로 연결 |
| 결과가 자동 재생으로 지나감 | 내가 만든 원인을 다시 확인하기 어려움 | 6개 장면 타임라인, 클릭 되감기, 각 장면의 반영 결정 칩 제공 |
| 모바일 시작 후 첫 장면 상단이 잘림 | 중요한 첫 피드백을 놓침 | 재생 전환 시 내부 스크롤을 0으로 초기화 |
| 실패했는데 100점으로 표시 | 결과 신뢰도 저하 | 전술 완성도와 경기 결과를 함께 반영한 감독 점수로 수정 |

## 검증 흐름

1. 경기 선택 후 밝은 전술 보드에서 11명을 드래그하고 포메이션·강도·교체를 조정한다.
2. 전술 지문에서 3-4-3, 속도 8 · 폭 8, 압박 7 · 위험 8, 펠라이니·샤들리를 확인한다.
3. 현장 지시를 선택한다. 벨기에 시나리오에서 박스 과부하는 xG를 3.12 → 3.40, 상대 xG를 0.83 → 0.98로 바꿨다.
4. 첫 장면에서 22명 위치, 공의 이동, 선택한 지시, 포메이션, 공격 폭, 교체 카드가 함께 표시된다.
5. 69분 전환 수비 장면을 타임라인에서 되감아 공격 숫자를 늘린 대가를 확인한다.
6. 감독 리포트에서 최종 3:3, 미션 실패, 감독 점수 85, 실제 경기·내 선택·코치 제안을 비교한다.

## 기능 검증

- 현장 지시 설계 유지, 박스 과부하, 전환 안전핀이 서로 다른 xG와 선수 위치를 만든다.
- 사용자가 드래그한 선수 좌표가 리플레이 장면 좌표에 반영된다.
- 모든 장면에 홈 11명과 원정 11명이 존재한다.
- 재생 속도, 결과까지 건너뛰기, 공개된 장면 되감기, 전술 편집 복귀, 리포트 진입이 동작한다.
- 390px에서 scrollWidth = clientWidth = 390이며 가로 넘침이 없다.
- 모바일 재생 시작 직후 shellTop = 0, pageY = 0이다.
- 새로고침 후 최근 실행 구간에서 콘솔 오류가 없다.
- npm test: 13/13 통과
- npm run build: 통과

## 남은 검증 범위

- 이 엔진은 실제 승률 예측 모델이 아니라 설명 가능한 체험형 로컬 시뮬레이션이다.
