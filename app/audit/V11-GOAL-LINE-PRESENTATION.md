# Touchline Replay 90 V11 골라인 판정 및 PPT 검증

검증일: 2026-07-11  
대상: 프로덕션 빌드 `http://localhost:4400/`

## 문제

기존 득점 이벤트는 일반 슈팅 좌표에서 공의 이동이 끝났고, 마지막 이동 구간의 55% 지점부터 `GOAL` 배너가 표시됐다. 공이 골문에 도착하지 않았는데 득점 판정이 먼저 보이는 시각적 불일치가 있었다.

## 수정

1. 득점 장면은 슈팅 지점 뒤에 상대 골문 안쪽 좌표를 네 번째 경로점으로 추가했다.
2. 실점 장면은 슈팅 지점 뒤에 우리 골문 안쪽 좌표를 네 번째 경로점으로 추가했다.
3. 골문 x 좌표는 `44%~56%`, 득점 y 좌표는 `4.4%`, 실점 y 좌표는 `95.6%`로 제한했다.
4. `GOAL` 연출은 마지막 프레임 전환의 90% 이후 또는 최종 프레임에 도착했을 때만 시작한다.
5. 일반 슈팅과 수비 이벤트는 기존 3개 경로점과 이벤트 좌표를 그대로 유지한다.

## 실제 브라우저 검증

한국-가나 코치 플랜을 적용하고 61분부터 97분까지 시뮬레이션을 직접 재생했다.

- 최종 공 좌표: `left: 48%; top: 4.4%`
- 득점 경로: `50,78 → 78,47 → 48,17 → 48,4.4`
- 득점 시점 클래스: `is-goal-moment is-us`
- 결과: 공이 상대 골문 안쪽에 도착한 상태에서 `GOAL` 배너 표시
