# Touchline Replay 90 UX 및 코드 감사

감사일: 2026-07-10  
대상: 4개 월드컵 결정 시나리오를 제공하는 감독 전술 시뮬레이터  
검증 환경: Codex 인앱 브라우저, 1440 x 900 데스크톱 및 390 x 844 모바일

## 결론

핵심 경험은 `결정 직면 -> 전술 조작 -> 변화 추적 -> 경기 시뮬레이션 -> 실제 경기 비교`로 명확하다. 이번 감사에서는 단일 경기 데모를 네 가지 위기 유형으로 확장하고, 사용자의 수정이 점수만 바꾸는 문제가 아니라 xG, 득점 경로, 실점 장면, 최종 스코어까지 이어지도록 경기 엔진을 교체했다.

제품의 독보적 사용 이유는 다음 한 문장으로 정리한다.

> 축구를 몰라도 10초 안에 감독의 결정을 만들고, 그 선택이 왜 다른 경기 장면과 결과를 만들었는지 실제 경기와 비교하며 이해하는 결정 리플레이.

## 스타디움 경험 개선

- 시작과 시뮬레이션 오버레이에 터치라인 시점의 원본 경기장 파노라마를 사용해 입장과 재생 순간을 분리했다.
- 경기별 홈·원정·강조 색을 스코어보드, 시나리오 카드, 진행 바에 연결해 경기 전환을 즉시 인지하게 했다.
- 경기장, 날짜, 현장 압박 문구, `TECHNICAL AREA` 상태를 한 줄에 제공해 별도 설명 없이 현재 맥락을 전달한다.
- 관중음은 기본 꺼짐이며 사용자가 직접 켤 수 있다. 외부 녹음이 아닌 자체 합성 WAV를 우선 재생하고, 지원 브라우저에서는 Web Audio를 폴백으로 사용한다.
- 데스크톱 1440 x 900과 모바일 390 x 844에서 텍스트 겹침, 가로 넘침, 핵심 CTA 누락이 없음을 확인했다.

## 남은 위험

- 경기 엔진은 실제 승리 확률 예측이 아니라 설명 가능한 체험 모델이다. 앱과 기획서에서 이 구분을 유지해야 한다.
- 선수 능력치와 상대 프로필은 시연용 큐레이션 값이다. 제출 README에 산출 근거와 비공식 모델임을 계속 고지해야 한다.
- 브라우저 전체 흐름은 실제 화면으로 검증했지만 CI에서 실행되는 자동 E2E는 아니다. 배포 URL 확정 후 주요 브라우저 스모크 테스트를 한 차례 더 수행한다.
- 현재 Codex 내장 검증 브라우저는 오디오 API를 노출하지 않아 실제 음향 출력은 확인하지 못했다. Chrome·Edge·Safari 배포 스모크 테스트에서 관중음 재생을 별도 확인한다.
- FIFA 보고서 URL과 데이터 사용 고지는 최종 저장소 동결 전에 다시 확인한다.
