# Security Policy

## Supported version

Only the current `main` branch and the active Vercel production deployment are supported.

## Reporting a vulnerability

Please do not disclose a vulnerability in a public issue. Send a private report through GitHub's **Security → Report a vulnerability** flow when available. Include the affected route or commit, reproduction steps, impact, browser, operating system, and a minimal proof of concept without personal or secret data.

This project has no login, backend database, payment flow, runtime API key, or server-side user storage. Browser progress is stored locally on the user's device.
